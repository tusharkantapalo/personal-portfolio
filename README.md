<h2>📖 About the Project</h2>

<p>
This repository contains the source code for my personal portfolio website. The website
is designed to present my academic background, technical skills, projects, experience,
and other professional information in a clean and modern interface.
</p>

<p>
The portfolio is built using standard web technologies and is hosted using
<b>GitHub Pages</b>.
</p>

<hr>

<h2>✨ Features</h2>

<ul>
    <li>🎨 Clean and modern user interface</li>

<h2>🚀 Getting Started</h2>

</pre>

<h3>2️⃣ Navigate to the Project</h3>

<pre>

</pre>

<h3>3️⃣ Open the Project</h3>

<p>
